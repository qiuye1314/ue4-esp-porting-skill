# FPS2_debug.txt 调试报告字段读法（远程调参唯一通道）

「导出调试报告」按钮写 /sdcard/Download/FPS2_debug.txt，字段：
- 相机: x,y,z rot(pitch,yaw) Fov Matrix调试=<矩阵哈希>
  * rot 与屏幕转向不一致=符号/索引错；矩阵哈希变了=W2S 数据源变了
- DrawIo:<42位01串> 位义: 1框 2距离 3射线 4骨骼 5信息 6血量 7地址 8全骨骼点 9队友 10尸体
  20自瞄主开关 22自瞄范围 24准心射线 30框内 31掩体判断 42采键中
  * 用户报"没效果"先看位串定位开关真实状态（v13 就是靠 bit20=0 抓到主开关旁路 bug）
- NumIo[3]自瞄启动像素 [4]速度 [5,6]锚点 [7]触摸范围 [19]盒高倍率 [25]自瞄世界距离
- Aim: MaxPlayerCount Gmin Fov 准心px 触点 键位
- 每行敌人: #idx scrD=屏幕距准心px wodD=世界米 vis=1露/0全挡 ray=头/胸/裆最近命中距(len=胸射线总长)
  读数法：ray=1000000000 → 该部位线没人没墙(可见)；ray≈挡距 → 该距处有几何。
  vis=0 但屏幕肉眼可见 → 场景多了假几何或缓冲吃掉了真墙，比对 ray 与 len 差值定位。
- 敌人坐标 aim=(x,y,z) mov=(预测)：aim 全是 (0,0,67) = 幽灵actor 混入
