# FPS2 版本迭代记录（v1→v18，踩坑→结论）

| 版本 | 改动 | 用户现象 | 教训/结论 |
|---|---|---|---|
| v1-v3 | 模板直改偏移，ESP可用 | 自瞄无效+多画一人 | 幽灵actor(0,0,67)未部署；自瞄未接世界坐标 |
| v4 | 自瞄接通 | 只有框变红才自瞄 | Blocked门与变色不同步；死区阈值70px太苛刻 |
| v5 | 比例拽+滑动阈值 | 乱瞄；掩体同色 | findminat 乒乓；射线打中目标自身刚体恒判挡 |
| v6 | 终点回拉130 | 贴墙露出不变色 | 回拉过头吃掉真墙命中 |
| v7 | 去掉rigid场景 | 掩体全失效 | FPS2 主掩体恰恰在 rigid(61)里，st(52)只有硬建筑 |
| v8 | rigid+start/endZone | 乱瞄改善 | 幽灵过滤(-600<z-camz<1400)成立 |
| v9 | 世界坐标锁定滞回0.45 | 抖动残留 | 死区12px不够→24px |
| v10 | 远距窗口放宽 | 远了不画(游戏streaming滞后,不可修) | 接受数据链极限 |
| v11 | 主开关=指示+子开关触发 | 用户否定：要默认生效 | 触发门语义先做错了方向 |
| v12-13 | 触发门+未截取判否 | 关主开关仍在瞄(bit20旁路bug) | 硬闸必须函数首行 return+Up |
| v14 | 第二指自动开火 | 用户要回连续 | 开火兜底"任意触点"=摇杆误触发万恶之源 |
| v15 | 双触发开关矩阵 | "一个都没效果"(未截取+FOV恒90) | 判定依赖数据采集成功率 |
| v16 | 分部位可见+前移60/45 | 近红远绿(110豁免+2%窗口两端失衡) | 距离对称过滤会制造反向bug |
| v17 | 原版语义+40/60 | 贴脸endZone<start恒可见=近必红复发 | 原版过滤层数就是为PUBGM干净场景写的 |
| v18 | 定版：连续自瞄(初版)+v16掩体分部位滞回 | - | 用户拍板组合 |

## 硬事实清单（FPS2）
- C2W=Mesh+0x1C0（四元数模1/平移贴rootPos 验证过；0x1A0 是局部偏移变换 t=(0,-90,0)，候选顺序 0x1C0 在前）
- 骨骼缓存 0x740/0x750/0x758 恒空 → 几何伪骨骼是永久方案不是过渡
- pawn+0x632 HoldingFire 恒 0 → evdev(TP) 可读触点(1080×2408 竖屏物理单位，与注入 Down 同空间)
- AppBase.Fov 恒 90（开镜不改）→ 开镜自瞄判据在 FPS2 不可用(FOV法)
- 类前缀 BP_AI_Pawn_A/B/C，队伍字节 0x4C8（0=己）
- 未部署actor停在(0,0,67)；远处敌人坐标streaming滞后2-3s（画不出近处才画=游戏数据极限，向用户解释过）
- Embree: dyn=61(含角色+活动掩体) st=52(建筑) hf=0；rigid不可去
